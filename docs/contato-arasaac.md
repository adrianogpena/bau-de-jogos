**Assunto:** Uso de pictogramas em app educativo gratuito para crianças

Olá, equipa ARASAAC,

Estou a criar o **Baú de Jogos**, uma coleção de jogos educativos para crianças de Portugal e do Brasil, pensada para tablet (PWA instalável). Os dois primeiros jogos ensinam a ler e a escrever palavras a partir de imagens, e queremos usar pictogramas do ARASAAC.

Condições do projeto:

- **Totalmente gratuito**, sem anúncios, sem login e sem recolha de dados das crianças.
- Código aberto no GitHub: <https://github.com/adrianogpena/bau-de-jogos>
- Os pictogramas são descarregados e guardados no repositório (não usamos a API em tempo real), com a licença **CC BY-NC-SA** em ficheiro e uma ecrã de **Créditos** no app a indicar ARASAAC, o autor Sergio Palao e a licença.
- Não alteramos os pictogramas.

Gostaríamos de confirmar que este uso é compatível com a licença e se há alguma indicação adicional de atribuição que devamos seguir. Se o projeto algum dia deixar de ser gratuito, removeremos os pictogramas.

Obrigado pelo vosso trabalho!
